# 新成员进群欢迎

群里有新成员加入时，自动发送**真正 @ 对方**的欢迎语；可选退群提示。

> 插件 ID（目录名）：`group_welcome`

## 一、安装

1. `group_welcome/` 放到
   `/storage/emulated/0/Android/media/com.tencent.mm/WCX/脚本插件/group_welcome/`
   （或导入 `group_welcome.zip`）
2. 总开关 + 本插件开关打开
3. 点齿轮设置欢迎语，或直接用默认模板

## 二、真实 @ 是怎么实现的

插件发送的文本里带占位符：

```java
sendText(group, "[AtWx=wxid_x]欢迎 小明 加入本群！");
```

脚本运行时会把它替换成 `@小明\u2005欢迎 小明 加入本群！`，并把 `wxid_x` 写入
`msgsource.atuserlist`。效果与手动 @ 一致：对方会收到「有人@我」提醒。

> 纯文本里手打 `@小明` 不会触发提醒，必须走这个占位符。

## 三、配置项

| 键 | 默认 | 说明 |
|---|---|---|
| `join_template` | `欢迎 {name} 加入本群，请先看群公告～` | 入群欢迎语，留空则关闭 |
| `leave_template` | 空 | 退群提示语，留空则不发送 |
| `groups` | 空 | 只在这些群生效（逗号分隔 `xxx@chatroom`），留空=所有群 |
| `at_member` | `true` | 是否 @ 新成员 |
| `delay_ms` | `1200` | 延迟发送，避开秒退/广告号 |
| `max_per_minute` | `5` | 每分钟最多触发次数，`0` 不限制 |
| `skip_self` | `true` | 自己进群时不发 |
| `enabled` | `true` | 插件内总开关 |

模板占位符：

- `{name}`：成员昵称（取不到时退化为群名片 / 备注 / wxid）
- `{group}`：群名称
- `{wxid}`：成员 wxid

## 四、行为说明

- 依赖微信的「成员变动」系统提示解析，`type` 为 `join` / `left`
- 同一人 10 分钟内只欢迎一次（防止重复系统消息刷屏）
- 每分钟触发次数超限会跳过并写日志
- 发送走主线程延迟任务，插件卸载时会自动取消未发送的任务
- 日志：插件目录 `log.txt`

## 五、常见问题

| 现象 | 排查 |
|---|---|
| 不进群欢迎 | 看 `log.txt` 有没有「欢迎新成员」；确认群 ID 在 `groups` 白名单里 |
| 没有 @ 提醒 | `at_member` 是否开启；确认发送的是群聊 |
| 欢迎语重复 | 检查是否有多个插件/多个设备同时开启 |
| 昵称是 wxid | 该成员资料还没同步，属正常退化 |
| 发送失败 | 可能被微信风控限制，调大 `delay_ms` |

## 六、注意

- 群成员变动依赖系统提示，部分微信版本/被折叠的提示可能识别不到
- 欢迎语过于频繁可能触发风控，建议保留默认的每分钟上限
